# BAI Mid-Term Project — file map

Satellite-mission vulnerability prioritisation. Deadline 1 Oct 2026, 23:59. Deliverable: 4 pages + 1-page GenAI appendix, put in `report/`.

| Folder | Holds |
|---|---|
| `brief/` | Assignment inputs (Instructions, Project Topics, professor note). Read-only. |
| `topic/` | `Topic_Brainstorm_Report.md`: topic decision and open questions. |
| `research/` | `Research_Plan.md` → `Research_Findings.md` → `Research_Findings_Explained.md`; `raw/` = subagent logs, never edited. |
| `report/` | Spec, plan, viva prep, the draft and (later) the final submission. Current draft: `Periapt_Report_Draft.md` (written overnight, reviewed with the user on 1 Oct). Overnight decisions: `logs/Overnight_Draft_Log_2026-09-30.md`. |
| `logs/` | `TRANSCRIPT_LOG.md` + `exports/` (source for the GenAI appendix). Generated by `/transcript`; historical text is not rewritten. |
| `scripts/` | `transcript.py` and its test; `build_drive_pack.py` rebuilds `Periapt_Drive_Pack/`. |
| `Periapt_Drive_Pack/` | Upload folder for Google Drive (copies of the documents + transcripts split by conversation). Gitignored, generated: never edit by hand. |

Flow: `research/raw` → `research/Research_Findings*` → `topic/` → `report/`.
New `/export` dumps go in the project root; `/transcript` files them into `logs/`.
Git: `docs/<topic>` branch, small commits, `merge --no-ff`, no push.
